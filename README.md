# 🚗 RoadAssist - Roadside Vehicle Assistance & Mechanic Booking Platform

RoadAssist is a responsive web application that helps vehicle owners quickly find nearby mechanics and request emergency roadside assistance. The platform allows users to manage vehicles, book mechanics, track emergencies, and upgrade to premium services.

---

## 📌 Features

- 🔐 User Login & Registration
- 🏠 Interactive Dashboard
- 🚗 Vehicle Management (Add, Edit, Delete)
- 🔧 Find Nearby Mechanics
- 📅 Mechanic Booking
- 🚨 Emergency Roadside Assistance
- 📖 Booking History
- 🚑 Emergency History
- 👤 User Profile Management
- ⭐ Premium Membership
- 💾 Local Storage Data Persistence
- 📱 Fully Responsive UI

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/aryanson007/roadside-assistance.git
```

Go inside the project

```bash
cd roadside-assistance
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
